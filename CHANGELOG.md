# Changelog

## 1.0.0 - 2026-10-06

First release.

- SVG QR code for the current tab's URL: black modules, transparent background, no padding
- In-page popover, with the regular popup as a fallback on pages extensions can't script
- UTM fields and custom query parameters, optionally remembered between uses
- Error correction level L, M, Q or H
- Download as SVG and copy the final URL
- Toolbar icon follows the browser's light/dark mode
