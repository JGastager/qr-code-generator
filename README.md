# QR Code Generator (Chrome extension)

Generates a QR code for the current tab's URL as an SVG: black modules on a transparent background, with no padding. You can add UTM parameters before downloading.

## Install (unpacked)

1. Open `chrome://extensions`
2. Turn on **Developer mode**
3. Click **Load unpacked** and select this folder

## Features

- Clicking the toolbar icon opens a rounded popover in the top-right of the page. Click the icon again, click outside, press Esc or use × to close it. On pages extensions can't script (`chrome://`, the Web Store), the regular popup opens instead.

- Pre-fills the active tab's URL. You can edit it.
- UTM fields (`utm_source`, `utm_medium`, `utm_campaign`, `utm_term`, `utm_content`) and any number of custom query parameters. These replace existing parameters that have the same name, and the `#hash` is kept.
- Parameters are remembered between uses (you can turn this off).
- Error correction level: L, M, Q or H.
- **Download SVG** saves the code as a file named after the page, for example `qr-example.com-products.svg`.
- **Copy URL** copies the final URL with the parameters added.

## Files

- `manifest.json`: Manifest V3, permissions `activeTab` and `storage`
- `popup.html`, `popup.css`, `popup.js`: the UI and logic, used by both the popover and the fallback popup
- `content.js`: injected on click; shows `popup.html` in a rounded popover inside a closed Shadow DOM
- `lib/qrcode.js`: [qrcode-generator](https://github.com/kazuhikoarase/qrcode-generator) 1.4.4 by Kazuhiko Arase (MIT)
- `background.js`, `offscreen.html`, `offscreen.js`: switch the toolbar icon between a dark and a light glyph to match the browser's light/dark mode
- `icons/`: generated by `node tools/generate-icons.js`
  - `icons/light/` and `icons/dark/`: monochrome toolbar glyphs
  - `icons/icon*.png`: colored tile for the extensions page and Web Store
